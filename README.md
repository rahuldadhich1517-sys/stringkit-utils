# StringKit

A lightweight, dependency-free TypeScript utility library for string and text manipulation.

[![npm version](https://img.shields.io/npm/v/stringkit.svg)](https://www.npmjs.com/package/stringkit)
[![npm downloads](https://img.shields.io/npm/dm/stringkit.svg)](https://www.npmjs.com/package/stringkit)
[![License](https://img.shields.io/npm/l/stringkit.svg)](LICENSE)

## Features

-  Lightweight
-  Zero runtime dependencies
-  Written in TypeScript
-  ESM and CommonJS support
-  Simple and composable API
-  Tested with Vitest
-  Unicode-aware utilities

## Installation

```bash
npm install stringkit-utils
